当前项目本身已经是“普通问答 + RAG + 多 agent 深度研究 + 报告生成 + 图表 + 知识图谱 + 数据库探索”的复合系统，不是单一聊天机器人；DeepResearch V2 已经具备规划、搜索、分析、写作、审核和补充研究的流水线能力。 DeepResearch V2 的核心文件集中在 `backend/app/service/deep_research_v2`，当前实际执行的是 `graph.py` 中 `_run_simplified` 手写流程，而不是完整 LangGraph，这一点要保留，因为它服务于当前实时 SSE 流式输出。

# 一、给 Codex 的总任务说明

## 1.1 项目目标

将当前偏行业/金融研究的 DeepResearch V2 agent 系统，重构为**法律风控 DeepResearch Agent**。

第一阶段只做 agent 层和后端领域层重构，不大改前端，不大改路由，不大改数据库结构，不重做认证体系。

最终效果：

```text
用户输入法律风控问题
        ↓
法律任务规划
        ↓
法规 / 案例 / 合同 / 处罚 / 企业风险信息检索
        ↓
证据与条款抽取
        ↓
法律风险识别、义务提取、风险评分
        ↓
法律风控报告生成
        ↓
法律质量审查
        ↓
补充检索 / 修订 / 完成
```

## 1.2 不允许破坏的接口

Codex 必须保持以下接口不破坏：

```text
POST /research/stream
GET /research/checkpoint/{session_id}
GET /research/checkpoint/{session_id}/full
POST /research/cancel/{session_id}
POST /research/resume/{session_id}
```

当前 `/research/stream` POST 默认走 DeepResearch V2，前端主要调用 POST；请求参数包括 `query`、`session_id`、`max_iterations`、`kb_name`、`search_web`、`search_local`、`search_modes`、`version`，其中 `search_modes` 优先于 `search_web/search_local`。

不要新增任何前端必须传的新必填字段。新增字段必须是后端内部默认值或可选字段。

## 1.3 不允许破坏的 SSE 机制

当前每个 agent 通过 `BaseAgent.add_message()` 把事件写入 `state["_message_queue"]`，`graph` 每 0.5 秒读取队列并 yield，`service` 格式化为 SSE，前端立即显示。

Codex 必须继续使用这个机制，不要改成一次性返回，不要改成后台任务，不要破坏前端流式展示。

```python
from typing import Dict, Any
from app.config.legal_risk_config import score_to_level


class RiskScoringService:
    """法律风控风险评分服务。"""

    WEIGHTS = {
        "impact_score": 0.30,
        "probability_score": 0.20,
        "legal_certainty_score": 0.15,
        "evidence_strength_score": 0.15,
        "urgency_score": 0.10,
        "remediation_difficulty_score": 0.10,
    }

    @classmethod
    def normalize_score(cls, value: Any, default: float = 3.0) -> float:
        try:
            score = float(value)
        except (TypeError, ValueError):
            return default
        return max(1.0, min(5.0, score))

    @classmethod
    def score_risk(cls, risk: Dict[str, Any]) -> Dict[str, Any]:
        total = 0.0
        for key, weight in cls.WEIGHTS.items():
            total += cls.normalize_score(risk.get(key)) * weight

        risk["overall_score"] = round(total, 2)
        risk["risk_level"] = score_to_level(total)
        risk["severity"] = risk["risk_level"]
        return risk
```

```python
from typing import Any, Dict, List


class CitationVerifierService:
    """基础证据链核验服务。第一阶段做结构完整性检查。"""

    REQUIRED_SOURCE_TYPES = {
        "law",
        "regulation",
        "judicial_interpretation",
        "case",
        "court_decision",
        "enforcement",
        "contract",
        "internal_policy",
        "regulator_guidance",
        "company_record",
    }

    @classmethod
    def verify_risk_items(cls, state: Dict[str, Any]) -> List[Dict[str, Any]]:
        checks: List[Dict[str, Any]] = []
        evidence_ids = {
            item.get("evidence_id")
            for item in state.get("evidence_chain", [])
            if item.get("evidence_id")
        }
        legal_source_ids = {
            item.get("source_id")
            for item in state.get("legal_sources", [])
            if item.get("source_id")
        }

        for risk in state.get("risk_items", []):
            risk_id = risk.get("risk_id", "")
            linked_evidence = risk.get("evidence_ids", []) or []
            linked_basis = risk.get("legal_basis_ids", []) or []

            missing_evidence = [
                ev for ev in linked_evidence if ev not in evidence_ids
            ]
            missing_basis = [
                src for src in linked_basis if src not in legal_source_ids
            ]

            status = "passed"
            if not linked_evidence and not linked_basis:
                status = "missing"
            elif missing_evidence or missing_basis:
                status = "weak"

            checks.append({
                "target_id": risk_id,
```
